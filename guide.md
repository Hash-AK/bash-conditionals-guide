# Bash Conditionals: if, else, elif and case

In many scripts that you will write, there will be, at one point, a need to take decisions based on _something_. Whether it's an argument, a variable value, an exit code, etc. To do that, you'll need to use _conditionals_.

Conditional, as you may deduce from the name, let you take actions based on one (or more!) conditions. In this guide I will show you how to use them properly in a script. 

There's 4 conditionals in Bash: `if`, `else`, `elif`, and `case`. We will go over here in the following sections. If you just need a quick reference table, scroll [to the end of the guide](#TO ADD WHEN WRITTEN)!
